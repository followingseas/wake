로컬 `~/.claude`에 남은 Claude Code 대화기록을 열람하고, 터미널로 이어가고, fork하고, 정리하는 데스크톱 뷰어입니다.

### 주요 기능

- 프로젝트별 세션 탐색과 검색 (⌘F)
- 문서형 대화 뷰어 (마크다운 조판, 도구 호출·사고 과정 접기)
- 터미널에서 이어가기 / Fork로 열기 (설정에서 터미널 선택 가능)
- 세션 휴지통 삭제

### 참고

- Intel Mac·Windows·Linux 빌드는 아직 제공하지 않습니다 (소스 빌드는 가능)
- 이어가기/Fork에는 `claude` CLI가 필요합니다
